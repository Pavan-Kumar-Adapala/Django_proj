**Polling Application with Automated CI/CD Pipeline using GitHub Actions**
**Project Type:** Independent Project  
- Developed a **Django-based polling application** with a structured **branching strategy** using **main** and **development** branches for efficient collaboration.
- Implemented **GitHub Actions CI/CD pipeline** to automate **code quality checks and unit testing** on pull requests to the development branch.
- Configured **Flake8 and Pylint** for **code quality analysis** and **linting tests**, ensuring adherence to Python coding standards.
- Integrated **unit testing with Django's test framework**, utilizing **GitHub Secrets** for securely managing environment variables.
- Optimized **dependency caching** in the GitHub Actions workflow to improve pipeline execution efficiency.
**Environment:** Django | Python | GitHub Actions | Flake8 | Pylint | Git and GitHub

  **Abstimmungsanwendung mit automatisierter CI/CD-Pipeline unter Verwendung von GitHub Actions**  

**Projekttyp:** Eigenständiges Projekt  

- Entwickelte eine **Django-basierte Abstimmungsanwendung** mit einer strukturierten **Branching-Strategie** unter Verwendung von **Main- und Development-Branches** für eine effiziente Zusammenarbeit.  
- Implementierte eine **CI/CD-Pipeline mit GitHub Actions**, um **Code-Qualitätsprüfungen und Unit-Tests** bei Pull Requests in den Development-Branch zu automatisieren.  
- Konfigurierte **Flake8 und Pylint** zur **Code-Qualitätsanalyse und Linter-Prüfung**, um die Einhaltung der Python-Codierungsstandards sicherzustellen.  
- Integrierte **Unit-Tests mit dem Django-Test-Framework** und nutzte **GitHub Secrets** zur sicheren Verwaltung von Umgebungsvariablen.  
- Optimierte das **Caching von Abhängigkeiten** im GitHub Actions-Workflow, um die Effizienz der Pipeline-Ausführung zu verbessern.  

**Technologie-Stack:** Django | Python | GitHub Actions | Flake8 | Pylint | Git und GitHub
